# Kuchařka — implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Statický web s osobní kuchařkou (56 receptů z Google Docs exportu) s hledáním bez diakritiky, kategoriemi a štítky, nasazený na Cloudflare Workers Static Assets.

**Architecture:** Astro 7 generuje čisté HTML z Markdown souborů v content collection `recipes`. Veškerá logika, kterou jde testovat, žije v čistých funkcích v `src/lib/` (slug, dělení sekcí, prostý text, hledání, řazení, formátování) a v `scripts/migrate/split-doc.ts`; `.astro` soubory jsou tenká prezentační vrstva ověřená Playwright testy. Jediný klientský JS je vyhledávací island s indexem vloženým přímo do úvodní stránky.

**Tech Stack:** Astro 7, Tailwind 4 (+ typography), TypeScript 6, marked, vitest, Playwright, tsx, yaml, wrangler. Node ≥ 22.12 (lokálně 24).

**Spec:** `docs/superpowers/specs/2026-09-28-cookbook-design.md`

## Global Constraints

- Jazyk webu i textů: **čeština**. `<html lang="cs">`.
- Astro **7**, statický výstup; Node **≥ 22.12**; TypeScript **^6** (ne 7 — `@astrojs/check` podporuje jen `^5 || ^6`).
- Slug = `slugify(title)` nebo `slugify(title)-N` (N ≥ 2), jen znaky `[a-z0-9-]`; rezervovaná jména Windows (`con`, `prn`, `aux`, `nul`, `com1`–`com9`, `lpt1`–`lpt9`) dostanou `-recept`.
- Sekce ingrediencí = první `## Ingredience` (trim + lowercase, přesná shoda) až po další `##`.
- Kategorie (pořadí je závazné): `snidane` Snídaně, `predkrmy-a-polevky` Předkrmy a polévky, `hlavni-chody` Hlavní chody, `dezerty` Dezerty a sladké, `svaciny` Svačiny, `ostatni` Ostatní.
- Štítky: kebab-case bez diakritiky (`^[a-z0-9]+(-[a-z0-9]+)*$`).
- Indexaci zakazuje jen `<meta name="robots" content="noindex">`; **žádný** `robots.txt`, sitemap, OG ani JSON-LD.
- Hledání: index vložený do úvodní stránky, žádný fetch. Porovnání lowercase + bez diakritiky, AND přes slova.
- Dark mode jen podle `prefers-color-scheme` (Tailwind `dark:`), bez přepínače.
- Hosting: Cloudflare **Workers Static Assets**, deploy ručně `./deploy.ps1` (`wrangler deploy`), ne git-connected.
- `migration/` je v `.gitignore` a **nikdy se necommituje** (obsahuje `source.md`).
- Vývojové prostředí Windows 11 + PowerShell; příkazy v plánu jsou pro PowerShell.

## Review Focus

1. **Soubory receptů s CRLF** (Windows checkout, `git` hlásí LF→CRLF) — `splitIngredients`, frontmatter parser v testu i split musí fungovat s `\r\n` stejně jako s `\n`. → testy v Task 3 a Task 5.
2. **Nadpisy z Google Docs exportu** — kotvy `{#…}`, escapy `\-` `\_` `\&`, `**tučné**`, prázdný `# ` nad obsahem dokumentu → čistý název a správný slug. → testy v Task 9.
3. **Dotaz s velkými písmeny, diakritikou a mezerami navíc** (`"  SVÍČKOVÁ   knedlík "`) má najít totéž co `svickova knedlik`; dotaz jen z mezer zobrazí vše. → test v Task 4.
4. **Kategorie bez receptů** — nesmí se objevit v hlavičce, na úvodní stránce ani vygenerovat stránku (odkaz by vedl na 404). → test v Task 5.
5. **Recept bez volitelných polí / bez sekce Ingredience** (Krevety) — detail se nesmí rozbít: žádné `undefined`, prázdné oddělovače ani dvojí vykreslení obsahu. → fixture `krevety.md` v Task 5, e2e v Task 7.

`src/lib/slug.ts`:
```ts
const RESERVED = new Set([
  'con',
  'prn',
  'aux',
  'nul',
  ...Array.from({ length: 9 }, (_, i) => `com${i + 1}`),
  ...Array.from({ length: 9 }, (_, i) => `lpt${i + 1}`),
]);

export function stripDiacritics(s: string): string {
  return s.normalize('NFD').replace(/\p{M}/gu, '');
}

export function slugify(title: string): string {
  const slug = stripDiacritics(title)
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '');
  if (!slug) throw new Error(`Z názvu nejde vytvořit slug: "${title}"`);
  return RESERVED.has(slug) ? `${slug}-recept` : slug;
}

export function uniqueSlug(base: string, taken: ReadonlySet<string>): string {
  if (!taken.has(base)) return base;
  for (let n = 2; ; n++) {
    const candidate = `${base}-${n}`;
    if (!taken.has(candidate)) return candidate;
  }
}

/** Soubor receptu se musí jmenovat slugify(title) nebo slugify(title)-N, N >= 2. */
export function isValidRecipeId(id: string, title: string): boolean {
  const base = slugify(title);
  if (id === base) return true;
  if (!id.startsWith(`${base}-`)) return false;
  const suffix = id.slice(base.length + 1);
  return /^[1-9]\d*$/.test(suffix) && Number(suffix) >= 2;
}
```

`src/lib/sections.ts`:
```ts
export interface IngredientSplit {
  before: string;
  ingredients: string | null;
  after: string;
}

const FENCE = /^ {0,3}(```|~~~)/;
const H2 = /^ {0,3}##(?!#)[ \t]+(.*?)(?:[ \t]+#+)?[ \t]*$/;

/**
 * Rozdělí tělo receptu na část před `## Ingredience`, samotnou sekci (po další `##`)
 * a zbytek. Spojení tří částí je vždy přesně původní text.
 */
export function splitIngredients(body: string): IngredientSplit {
  const lines = body.split(/(?<=\n)/);
  let inFence = false;
  let start = -1;
  let end = lines.length;

  for (let i = 0; i < lines.length; i++) {
    const line = lines[i].replace(/\r?\n$/, '');
    if (FENCE.test(line)) {
      inFence = !inFence;
      continue;
    }
    if (inFence) continue;
    const m = H2.exec(line);
    if (!m) continue;
    if (start === -1) {
      if (m[1].trim().toLowerCase() === 'ingredience') start = i;
    } else {
      end = i;
      break;
    }
  }

  if (start === -1) return { before: body, ingredients: null, after: '' };
  return {
    before: lines.slice(0, start).join(''),
    ingredients: lines.slice(start, end).join(''),
    after: lines.slice(end).join(''),
  };
}
```

/** Hrubý převod Markdownu na prostý text pro vyhledávací index. */
export function markdownToText(md: string): string {
  return md
    .replace(/```[\s\S]*?```/g, ' ')
    .replace(/!?\[([^\]]*)\]\([^)]*\)/g, '$1')
    .replace(/^[ \t]{0,3}#{1,6}[ \t]+/gm, '')
    .replace(/^[ \t]*(?:[-*+]|\d+[.)])[ \t]+/gm, '')
    .replace(/^[ \t]*>[ \t]?/gm, '')
    .replace(/(\*\*|__)(.*?)\1/g, '$2')
    .replace(/(^|[^\\\w])[*_](\S(?:.*?\S)?)[*_](?=\W|$)/g, '$1$2')
    .replace(/\\(.)/g, '$1')
    .replace(/\s+/g, ' ')
    .trim();
}

import { stripDiacritics } from './slug';

export interface SearchEntry {
  slug: string;
  title: string;
  category: string;
  tags: string[];
  text: string;
}

export function normalize(s: string): string {
  return stripDiacritics(s).toLowerCase();
}

export function tokenize(query: string): string[] {
  return normalize(query).split(/\s+/).filter(Boolean);
}

export function matches(entry: SearchEntry, query: string): boolean {
  const tokens = tokenize(query);
  if (tokens.length === 0) return true;
  const haystack = normalize([entry.title, ...entry.tags, entry.text].join(' '));
  return tokens.every((t) => haystack.includes(t));
}
```

```ts
import { CATEGORIES, type CategoryKey } from '../consts';

export interface RecipeLike {
  id: string;
  data: { title: string; category: CategoryKey; tags: string[] };
}

export interface CategoryGroup<T> {
  key: CategoryKey;
  label: string;
  recipes: T[];
}

export function sortByTitle<T extends RecipeLike>(recipes: readonly T[]): T[] {
  return [...recipes].sort((a, b) => a.data.title.localeCompare(b.data.title, 'cs'));
}

export function groupByCategory<T extends RecipeLike>(recipes: readonly T[]): CategoryGroup<T>[] {
  const sorted = sortByTitle(recipes);
  return CATEGORIES.map((c) => ({
    key: c.key,
    label: c.label,
    recipes: sorted.filter((r) => r.data.category === c.key),
  })).filter((g) => g.recipes.length > 0);
}

export function collectTags(recipes: readonly RecipeLike[]): string[] {
  return [...new Set(recipes.flatMap((r) => r.data.tags))].sort((a, b) => a.localeCompare(b, 'cs'));
}

export function withTag<T extends RecipeLike>(recipes: readonly T[], tag: string): T[] {
  return sortByTitle(recipes.filter((r) => r.data.tags.includes(tag)));
}
```

export function formatMinutes(min: number): string {
  const h = Math.floor(min / 60);
  const m = min % 60;
  if (h === 0) return `${m} min`;
  return m === 0 ? `${h} h` : `${h} h ${m} min`;
}

export function formatServings(n: number): string {
  return n >= 1 && n <= 4 ? `${n} porce` : `${n} porcí`;
}

  import { matches, type SearchEntry } from '../lib/search';

  function init() {
    const root = document.getElementById('search');
    const input = document.getElementById('search-input') as HTMLInputElement | null;
    const data = document.getElementById('search-index');
    const empty = document.getElementById('search-empty');
    if (!root || !input || !data || !empty) return;

    let entries: SearchEntry[];
    try {
      entries = JSON.parse(data.textContent ?? '');
    } catch (err) {
      console.error('Index hledání nejde načíst', err);
      return;

    const items = document.querySelectorAll<HTMLElement>('[data-slug]');
    const groups = document.querySelectorAll<HTMLElement>('[data-group]');

    const apply = () => {
      let visible = 0;
      items.forEach((li) => {
        const entry = bySlug.get(li.dataset.slug ?? '');
        const show = entry ? matches(entry, input.value) : true;
        li.hidden = !show;

```ts
import { slugify, uniqueSlug } from '../../src/lib/slug';

export interface RawRecipe {
  slug: string;
  title: string;
  chapter: string | null;
  body: string;
}

export interface SplitResult {
  recipes: RawRecipe[];
  /** Text mimo recepty (obsah dokumentu, úvody kapitol). */
  discarded: string;
  warnings: string[];
  errors: string[];
}

const HEADING = /^ {0,3}(#{1,6})(?:[ \t]+(.*?))?(?:[ \t]+#+)?[ \t]*$/;
const FENCE = /^ {0,3}(```|~~~)/;

/** Odstraní kotvu Google Docs `{#…}`, zvýraznění a Markdown escapy. */
export function cleanTitle(raw: string): string {
  return raw
    .replace(/\s*\{#[^}]*\}\s*$/, '')
    .replace(/(\*\*|__)(.*?)\1/g, '$2')
    .replace(/\\(.)/g, '$1')
    .trim();
}

export function splitDocument(source: string, level: number): SplitResult {
  if (!Number.isInteger(level) || level < 1 || level > 6) {
    throw new Error(`Neplatná úroveň nadpisu: ${level}`);
  }
  const lines = source.replace(/\r\n?/g, '\n').split('\n');
  const recipes: RawRecipe[] = [];
  const warnings: string[] = [];
  const errors: string[] = [];
  const discarded: string[] = [];
  const taken = new Set<string>();

  let chapter: string | null = null;
  let current: { title: string; chapter: string | null; lines: string[] } | null = null;
  let inFence = false;

  const flush = () => {
    if (!current) return;
    const { title, chapter: recipeChapter, lines: body } = current;
    current = null;
    let base: string;
    try {
      base = slugify(title);
    } catch {
      errors.push(`Nadpis "${title}" nedává použitelný slug — recept přeskočen.`);
      return;
    }
    const slug = uniqueSlug(base, taken);
    if (slug !== base) warnings.push(`Kolize názvu "${title}" — uloženo jako ${slug}.md`);
    taken.add(slug);
    recipes.push({ slug, title, chapter: recipeChapter, body: body.join('\n').trim() });
  };

  for (const line of lines) {
    if (FENCE.test(line)) inFence = !inFence;
    const m = inFence ? null : HEADING.exec(line);
    if (m) {
      const depth = m[1].length;
      const title = cleanTitle(m[2] ?? '');
      if (depth === level) {
        flush();
        current = { title, chapter, lines: [] };
        continue;
      }
      if (depth < level) {
        flush();
        chapter = title || null;
        discarded.push(line);
        continue;
      }
    }
    (current ? current.lines : discarded).push(line);
  }
  flush();

  return { recipes, discarded: discarded.join('\n').trim(), warnings, errors };
}

export function renderRaw(recipe: RawRecipe): string {
  const chapter = recipe.chapter ? `<!-- kapitola: ${recipe.chapter} -->\n\n` : '';
  return `# ${recipe.title}\n\n${chapter}${recipe.body}\n`;
}

Struktura těla (text se **nepřepisuje**, jen se mění nadpisy a pořadí bloků):

- `### Postup`, `### POSTUP:`, `### Instrukce` → `## Postup`; `### Postup <část>` → `### <Část>` pod `## Postup`.
- Střídané bloky (pizza, focaccia) seskup: všechny ingredience pod `## Ingredience`, všechny postupy pod `## Postup`, pořadí částí zachovej.
- „(N porce)"/„(N porcí)" z nadpisu ingrediencí → `servings: N`; mají-li části různé porce, nech je v podnadpisu a `servings` nevyplňuj.
